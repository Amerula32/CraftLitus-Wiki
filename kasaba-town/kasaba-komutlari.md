# 💻 Tüm Kasaba (Town) Komutları

Aşağıda Towny eklentisinde kullanabileceğiniz tüm temel ve gelişmiş kasaba komutları kategorize edilmiştir.

---

## 📌 Genel & Bilgi Komutları

```bash
/t                  # Kendi kasabanızın bilgilerini gösterir.
/t <kasaba_adi>     # Belirtilen kasabanın bilgilerini gösterir.
/t list             # Sunucudaki tüm kasabaları listeler.
/t online           # Kasabanızda çevrimiçi olan üyeleri gösterir.
/t spawn            # Kasabanızın doğma noktasına ışınlar.
/t spawn <kasaba>   # Başka bir kasabanın açık doğma noktasına ışınlar.
```

---

## 🏛️ Yönetim Komutları (Belediye Başkanı & Asistan)

```bash
/t deposit <miktar>     # Kasaba bankasına para yatırır.
/t withdraw <miktar>    # Kasaba bankasından para çeker.
/t set board <mesaj>    # Kasaba üyelerinin oyuna girince gördüğü duyuruyu değiştirir.
/t set mayor <oyuncu>   # Belediye başkanlığını başka bir oyuncuya devreder.
/t rank add <oyuncu> <rutbe> # Oyuncuya kasaba içi rütbe (Assistant, Builder vb.) verir.
/t rank remove <oyuncu> <rutbe> # Oyuncunun rütbesini geri alır.
/t delete               # Kasabayı tamamen siler (Geri alınamaz!).
```

---

## 🛡️ Kasaba Ayarları (Toggle)

```bash
/t toggle pvp       # Kasaba içi PVP'yi açar veya kapatır.
/t toggle fire      # Ateş yayılmasını açar veya kapatır.
/t toggle explosion # Patlamaları (Creeper/TNT) açar veya kapatır.
/t toggle mobs      # Kasaba içinde canavar doğmasını açar veya kapatır.
/t toggle open      # Kasabayı herkese açık (davetsiz katılım) yapar.
```
