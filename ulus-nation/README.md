# 👑 Ulus (Nation / Krallık) Rehberi

Birkaç kasaba güçlerini birleştirerek büyük bir **Ulus (Nation)** kurabilir. Uluslar sunucu haritasında büyük bir güç ve nüfuz elde eder.

---

## 🏛️ Ulus Nasıl Kurulur?

- Ulus kurabilmek için bir kasabanın Belediye Başkanı olmalısınız.
- Üzerinizde ve kasaba bankasında yeterli kurulum ücreti bulunmalıdır (Örn: **10.000$**).
- Komut:

```bash
/n new <Ulus_Adı>
```

Ulus kurulduğunda, kuran kasaba otomatik olarak o ulusun **Başkenti (Capital)** ilan edilir.

---

## 🤝 İttifaklar ve Düşmanlıklar

Ulus liderleri (Krallar) diğer uluslarla diplomatik ilişkiler kurabilir:

- **Müttefik Ekleme:** `/n ally add <Ulus_Adı>`
- **Düşman İlan Etme:** `/n enemy add <Ulus_Adı>`

{% hint style="info" %}
**Müttefik Avantajı:** Müttefik ulus üyeleri birbiriyle savaşmaz ve özel izin verilen ortak arazileri (Embassy) kullanabilirler.
{% endhint %}
