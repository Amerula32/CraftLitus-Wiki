# 💻 Tüm Ulus Komutları

Ulus yönetimi ve diplomatik işlemler için kullanılan komutların tam listesi:

---

## 📌 Genel & Bilgi Komutları

```bash
/n                  # Kendi ulusunuzun detaylarını gösterir.
/n <ulus_adi>       # Belirtilen ulusun bilgilerini gösterir.
/n list             # Sunucudaki tüm ulusları ve üye kasabaları listeler.
/n online           # Ulus genelinde çevrimiçi olan tüm oyuncuları gösterir.
```

---

## 👑 Kral & Yönetim Komutları

```bash
/n add <kasaba_adi>      # Bir kasabayı ulusunuza davet eder.
/n kick <kasaba_adi>     # Bir kasabayı ulusunuzdan çıkarır.
/n deposit <miktar>      # Ulus kasasına para yatırır.
/n withdraw <miktar>     # Ulus kasasından para çeker.
/n set capital <kasaba>  # Ulusun başkentini değiştirir.
/n set king <oyuncu>     # Krallık unvanını başka bir başkent sakinine devreder.
/n set title <oyuncu> <unvan> # Oyuncuya özel unvan verir (Örn: Dük, Lord).
/n delete                # Ulusu tamamen siler.
```
